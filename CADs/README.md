# Instructions for CAD Files

## CAD Files in `HEX10` folder

### HEX10 Sensor Model.SLDPRT
CAD model of the HEX10 sensor, used only for estimating the sensor's size and shape.

---

### Interface / Interface Shortened.SLDPRT
Interfaces on both sides of the HEX10 sensor. They share the same shape but have different lengths. The shortened interface is for the side near the end-effector.

---

### Sensor Attachment Setup.SLDASM
Assembly of the HEX10 sensor and its interfaces.

### 2 Part Cannula.SLDPRT

Used to mount the modified tool to the PSM. Because the HEX10 sensor cable runs along the shaft, the original cannula cannot be used.

---

## CAD Files in `Shaft Modification` folder

### Mount Base / Top.SLDPRT
Auxiliary parts to keep the shaft horizontal when cutting the slot for the HEX10 sensor.

---

### Shaft Horizontal Fixture.SLDPRT
Contains horizontal tabs that assemble to the original end-effector slot to ensure the shaft remains horizontal while cutting. Use together with the Mount Base to secure the shaft.

---

### Shaft Cutting Base.SLDPRT
Removes a specific length of the shaft to make room for the HEX10 sensor and interfaces.

---

### Slot Cutting Base / Top.SLDPRT
Cuts the HEX10 interface slot on the cut shaft cross section to the designated angle and shape.

---

### EE Cutting Fixture.SLDPRT
Cuts the shaft cross section near the end-effector for the shortened HEX10 interface slot while preserving the original tool orientation angle.

---

### Rotators Fixture.SLDPRT
Tool for fixing all four rotators when re-tensioning the cable spools.

---
